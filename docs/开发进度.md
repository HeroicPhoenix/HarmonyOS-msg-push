# 开发进度与验证记录

## 2026-10-21：新增 Codex 本轮处理完成通知服务端

### 变更

- 开始时工作区干净，按 AGENTS 读取开发记忆、进度、概览、接口说明及相关鉴权/MeoW/路由调用链。
- 新增 `app/codex.py`：严格的带连字符字段请求模型、项目目录名提取、原文空白整理和长度常量（标题 80、任务 120、回答 800，包含省略号）、UTC+08:00 接收时间。
- 新增 `app/routes/codex.py` 并在应用工厂注册 `POST /payload_codex`。复用 Settings、get_settings、verify_secret 与 push_meow，接收账号只使用服务端配置，跳转地址只取 DEFAULT_JUMP_URL。
- 只支持 `agent-turn-complete`。合法的其他事件返回固定 ignored 响应且不调用 MeoW；已知字段类型错误、非对象/非 JSON/无效编码等返回 422 且不推送。
- 新接口显式用 Pydantic 校验原始 JSON，并由同一模型生成 OpenAPI 请求说明，避免框架对部分无效编码返回 400；异步路由中的同步推送经线程池执行。
- 标题与正文只表达本轮处理完成并摘录原文，不推断任务成功、测试状态、排队消息或窗口空闲。ID 不入手机正文，不用本地路径或 ID 构造链接。
- 支持事件完成一次调用后返回 `ok: true` 与原始 meow_result；非 2xx、业务失败、超时均保留。新增应用日志只记录事件类型、会话/轮次 ID、忽略标记和推送 HTTP 状态。
- 新增 `tests/test_codex.py`；更新接口说明（含 curl 与接入协议）、源码索引/调用链、开发记忆；部署指南只补充新路径可能需要放行。
- 未改共享 push_meow、Settings、已有路由、依赖、Dockerfile 或 Compose；旧 `/payload` 保持 404。
